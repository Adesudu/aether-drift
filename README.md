Aether Drift is an action-packed top-down 2D canvas arena game where you pilot a nimble skiff through a drifting asteroid field, collect amber starshards, blast hazards, and upgrade your ship across escalating waves. Move with WASD/arrows, aim with the mouse, shoot with Space or click, and dash with Shift.

## Run it

```sh
node serve.ts
```
